# TikTok Location Minimal

Minimaalinen mobiiliystävällinen käyttöliittymä GitHub Pagesiin.

## Käyttöönotto
1. Korvaa repositorion vanhat `index.html`, `styles.css` ja `app.js` näillä tiedostoilla.
2. GitHub Pages päivittyy automaattisesti hetken kuluttua.

Huom: tämä versio ei vielä hae TikTok-profiilitietoja automaattisesti.
